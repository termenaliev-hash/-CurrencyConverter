# CurrencyConverter — Конвертер валют на Android

Учебный проект (Java). Конвертер валют с курсами из интернета, историей операций и избранными парами.

## Что реализовано
- Конвертация валют по актуальным курсам из сети.
- История последних операций.
- Функционал «Избранное» для быстрых переводов.
- Адаптивный интерфейс на ConstraintLayout.

## Как запустить проект
1.  Открыть проект в Android Studio.
2.  Дождаться синхронизации Gradle (кнопка Sync Now, если появится).
3.  Подключить Android-устройство по USB или запустить эмулятор.
4.  Нажать кнопку Run (зелёный треугольник ▶️).

## Технологии
- Java
- Android SDK
- ConstraintLayout
- HTTP-запросы (для получения курсов)
